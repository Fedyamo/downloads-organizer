# Downloads Organizer

A Python script that automatically organizes a messy `Downloads` folder:
it sorts files into category subfolders by year/month, renames them with
the modification date, and logs every operation.


**What it does:**

- Scans the `Downloads` folder (top level only, no subfolders)
- Detects file category by extension (`Documents`, `Images`, `Videos`,
  `Archives`, `Excel`, `Presentations`, `Books`, `Fonts`, `Apps`, `Torrents`,
  `Music`; anything else goes to `Others`)
- Переименовывает файлы с датой их изменения: `2026-10-15_отчет.pdf`
- Создает структуру папок по годам/месяцам: `Загрузки/2026/10/Документы/`
- Перемещает файлы в соответствующие папки
- Избегает перезаписи при конфликтах имен, добавляет `_1`, `_2`, и т.д.
- Регистрирует каждую операцию в `загрузки_организованные.log` и на консоль
- Печатает окончательное резюме: файлы обработаны, перемещены, ошибки

**Требования:** Python 3.12+, без внешних зависимостей.

**Бег:**
```баш
python main.py
```

## Умный органайзер Загрузки


Скрипт сканирует папку `Загрузки`, раскладывает файлы по категориям и датам,
переименовывает их и логирует все операции.

## Что делает

- Сканирует папку `Загрузки` (без захода в подпапки)
- Определяет категорию файла по расширению (`Документы`, `Изображения`, `Видео`,
  `Архивы`, `Эксель`, `Презентации`, `Книги`, `Шрифты`, `Приложения`, `Торренты`,
  `Музыка`; всё остальное — `Другие`)
- Переименовывает файл, добавляя дату изменения: `2026-10-15_отчет.pdf`
- Создаёт структуру папок по году и месяцу: `Загрузки/2026/10/Документы/`
- Перемещает файлы в соответствующие папки
- При конфликте имён не перезатирает файл, а добавляет суффикс `_1`, `_2`...
- Логирует все операции в файл `загрузки_организованные.log` и выводит в консоль
- Показывает итоговую статистику: сколько файлов обработано, перемещено, ошибок

## Тестирование без риска для реальных файлов

Перёд запуском на сайте Загрузок обзор сайта логику на сайте
тестовых данных:

```баш
тест Python.py
```

Это создаст папку `тестовые_загрузки` с набором файлов разных типов. Затем
временно измените путь в `main.py` на `Путь('test_downloads')`, запустите
`python main.py` и проверьте результат:

```баш
python -c "из pathlib импортировать Path; [print(p) для p в Path('test_downloads').rglob('*') если p.is_file()]"
```

## Лог операций

Все перемещения, ошибки и итоговая статистика пишутся в `загрузки_организованные.log`
в корне проекта. Пример записи:

```
[2026-10-15 14:32:02] ИНФОРМАЦИЯ | Перемещён: report.pdf -> 2026\10\Documents\2026-10-15_report.pdf
```

## Известные ограничения

- Удаление временных файлов (`.тмп`, `.температура`) не реализовано — в проекте не
  было такой необходимости
- Категория файла определяется только по расширению, без анализа содержимого
